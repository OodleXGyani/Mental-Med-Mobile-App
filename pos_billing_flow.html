### 🎯 Objective Implement and verify complete parity for the Point of Sale (POS) Billing workflow across the ERP backend, Web App POS, and Mobile POS client. --- ### 🔄 POS Billing Workflow Summary 1. **Customer & Cart Initialization**: - Fetch customer directory (`erp_pharmacy.api.user_page.customer.customer.get_customer_directory`). - On selecting customer, assign or retrieve ephemeral cart via `erp_pharmacy.api.user_page.cart.cart.get_or_assign_cart`. 2. **Item Selection & Sync**: - Add items via Medicine Search (`get_inventory_items`), Barcode Scanner, or Past Orders (`get_customer_invoices`). - Auto-sync local cart lines (`item_code`, `qty`, `rate`) with ERP using 1-second debounce on `save_cart`. 3. **Checkout Validation & Multi-Gate Approvals**: - On checkout, execute `checkout_preview` to get server totals + validation flags: a. **Discount Gate**: If discount % > user role limit, generate approval via `request_approval` and approve with manager PIN via `submit_approval`. b. **Prescription (Rx) Gate**: If schedule drug has no prescription, require override reason + manager PIN. c. **Margin Gate**: Enforce margin rules (Block / Admin PIN Override / Warn). 4. **Payment & Invoice Submission**: - Choose payment mode (`Cash`, `UPI`, `Card`). - Submit `create_pos_invoice` including cart name, payment breakdown, and all approved manager log IDs (`discount_approval_log`, `rx_override_log`, `margin_override_log`). - Receive submitted Sales Invoice ID and `print_url`. 5. **Post-Sale / Receipt**: - Render receipt modal with auto-print, PDF download, and WhatsApp share. - Reset POS state for the next customer.
