### 🎯 Objective Verify and maintain 100% architectural parity for the Point of Sale (POS) Billing workflow across ERPNext backend, Web POS, and Mobile POS clients. --- ### 🔄 End-to-End POS Lifecycle: 1. **Customer & Loyalty Initialization**: - Customer Search (`frappe.desk.search.search_link`). - Load loyalty balance (`get_customer_loyalty_info`) + assign ephemeral cart (`get_or_assign_cart`). 2. **Item Search & Batch Management**: - Query inventory (`get_medicine_inventory`), Salt filter (`search_link`), Barcode (`scan_barcode`). - Item Details Modal: fetch warehouses (`get_item_warehouses`), batches (`get_item_batches`), live rate/stock (`get_item_details`). - Enforce batch assignment for all batch-tracked medicines before checkout. 3. **Cart Sync & Auto-Discounts**: - Debounced (500ms) sync (`save_cart`) with `warehouse`, `batch_no`, line discounts. - Auto-discount engine preview (`get_applicable_discounts`). - Forced immediate `save_cart` on checkout button click. 4. **Checkout Preview & Multi-Gate PIN Approvals**: - Execute `checkout_preview` + `get_manager_users`. - **Discount Gate**: Validate against role limit (`check_discount_limit`) -> `request_approval` + Manager PIN via `submit_approval`. - **Prescription Gate**: Missing Schedule H/H1/X Rx requires reason + Manager PIN. - **Margin Gate**: Enforce margin (Block / Admin PIN Override / Warn). 5. **Payment Modes & Settlement**: - `Cash` / `UPI` / `Card` / `Online` (Razorpay link with 5s status polling via `verify_payment_link_status`). - Submit final `create_pos_invoice` with all approval log IDs. 6. **Receipting**: - Thermal/A4 print view & direct PDF download (`download_pdf`).
